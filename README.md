# Library Management System

A simple Library Management System built in Java to manage different types of library items (Books, Magazines, Videos, and Archived Documents). This system allows users to borrow and return items, and view the status of library items.

## Features

- **Add Library Items**: Add various items such as books, magazines, and other documents to the library.
- **Borrow and Return Items**: Borrow and return items from the library system.
- **Display Status**: View the current status of all library items (whether they are available or borrowed).
- **Search Library Items**: Search for an item by title and view its status.

## Technologies Used

- Java 11 or later
- Object-Oriented Programming concepts (Abstraction, Inheritance, Polymorphism, Encapsulation)
